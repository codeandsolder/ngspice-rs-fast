grounded reciprocal RC chain, 2/8/32 ports, 64 frequencies, 3 internal
trials per process. Checks every retained cell for finiteness and prints a
bit hash over the entire plot. Baseline code `118e91b` (accepted #34 with
benchmark only); candidate `4446c75`. Generic release, pinned nightly
1.102.0 (6905905bb, 2026-11-19), managed sccache. Acer Ryzen 7 4700U, eight
logical CPUs; one-minute load 44.60–45.08 during alternating runs.

Cumulative allocated bytes reduced by 52.6%, 77.0%, and 86.1% respectively.
Peak live increases slightly from retained scratch; the large retained plot
dominates peak for 32 ports. At 32 ports, baseline normal-solve scatter
allocations alone account for 9,437,184 bytes across 6,144 blocks in the
largest allocation stack (one block per driven-port solve, 32×64×3).
That stack disappears from the candidate profile. Plot-growth stacks
allocating 8,522,208 cumulative bytes over 7 blocks per trial become one
4,294,656-byte reservation per trial. Remaining heap costs include
frequency-specific generator enumeration and noise device metadata; these
are outside the reusable port algebra and solve workspace.
